# Assessment of original Foundation (`niov-foundation`)

Reference only. Not imported. Not forked for Phase 0.

## Valuable concepts to preserve

- Durable event orientation for compliance and audit
- Authorization and proof as first-class concerns
- Separation of governance substrate from product UX
- Agent and enterprise deployment discipline
- Memory of actions with verifiability

## Problems to avoid

- Assuming one global foundation is the product authority for social relationships
- Blind schema inheritance that forces Opal into non-social models
- Coupling human chat privacy to analytical durability without classification
- Operational complexity before product loops are proven
- Treating every stream consumer as equally trusted

## Potentially adaptable later (only after ADR + license + security review)

- Audit ledger patterns
- Capability / policy evaluation interfaces
- Provider adapter shapes
- Replay tooling ideas

## Must remain isolated

- Production Opal PII and conversation content
- Opal session and cookie authority
- Youth and relationship policies (Opal-owned)

## Incompatible legacy assumptions

- Foundation invents social graph truth
- External agents write Opal conversations directly
- Indiscriminate retention of private human content in general topics

## Phase 0 decision

**No code import.** Document lessons only. Explicit ADR required before any adaptation.
